# Call Bomber Simulator

A simple Call Bomber Simulator created for educational purposes. It simulates a call bomb effect without actually causing harm or any illegal activity.

## Features

- Simulate a Call Bomb effect.
- Click the "Start Bomb" button to simulate the effect.
- Educational tool to understand how a call bomb works (just a simulation).

## How to Use

1. Click on the "Start Bomb" button.
2. The call bomb simulation will start (this is just a simulation).
3. Enjoy exploring the features!
